# 虎妞视觉导演

## 触发场景
当用户提及「虎妞视觉」「东方小虎妞」「虎妞信息图」「用虎妞风格做AI知识图」时启用。

## 核心流程
1. **内容理解**：提炼主题、读者、核心结论和可核查数据，区分确定事实和推测。
2. **信息结构**：先安排标题、说明、分组、流程关系，再考虑角色和装饰。
3. **角色一致性**：保持黑色双丸子头、虎耳、虎尾、金棕眼睛与小虎牙；未经指示不换人设。
4. **视觉表达**：默认16:9、暖白/朱砂红/墨黑/少量暖金、现代编辑式三栏卡片；确保文字可读、适当留白。
5. **审查迭代**：检查文字错误、逻辑层级、角色识别度、视觉噪声与边界，按优先级修正。
6. **交付与归档**：保留源提示词、导出图和版本说明；源资产未提供时不声明存在。

## 关键约束
- 角色服务内容表达，不应侵占主要图表空间。
- 不编造图表数值、引用或技术事实。
- 生成涉及中文文字时逐项校对，必要时把文字与背景分层后期排版。
- 优先保留主体比例、面部和IP标志性细节。
- 有参考图时提炼构图、色彩、材质、排版分别应用，不机械复制。
