# 虎妞视觉 · Huniu Visual Director

独立于「阿搭」的东方小虎妞视觉创作子模块。当前版本为 **v0.1 GitHub 初始重建版**，根据既定视觉设定建立可执行的 Skill 骨架；并非此前 ZIP 包的逐字还原。

## 视觉定位
- 角色：东方小虎妞；黑色双丸子头、虎耳与虎尾、金棕眼睛、可爱小虎牙。
- 视觉：现代编辑式信息设计；暖白、朱砂红、墨黑，少量暖金。
- 默认画幅：16:9 信息图；按任务可调整。
- 核心用途：AI 技术知识图解、工具介绍、系统架构图、视觉封面。
- 角色职责：辅助解说而非遮盖核心内容。

## 使用
阅读 [SKILL.md](./SKILL.md)，再结合 [视觉规范](./references/visual-rules.md) 创作。
