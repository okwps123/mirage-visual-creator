# 东方小虎妞 · 视觉基准 V1.0

## 品牌与形象
- 东方中式 Q 版角色；黑色双丸子头、虎耳、虎尾、金棕眼睛、小虎牙。
- 温暖、灵动、俏皮，但表达专业知识时不喧宾夺主。
- 保持不同场景下的角色轮廓、发型、眼睛、面部识别度一致。

## 配色与排版
- 主背景：暖白与浅奶油色。
- 主强调：朱砂红。
- 主文字：墨黑。
- 次级点缀：少量暖金。
- 默认：16:9、现代编辑风格、三栏卡片、清晰标题层级。
- 重要图表须优先保证阅读顺序和标注准确度。

## 推荐信息图结构
1. 左上：品牌名与主题大标题。
2. 中间：三栏内容卡片或一个主流程图与右侧关键要点。
3. 右上或角落：虎妞作为视觉引导。
4. 底部：一句高信息密度的总结与必要出处。

## 质量检查
- 标题是否能在缩略图上辨认？
- 三秒内能否理解主题及主结论？
- 角色是否清晰、与设定一致？
- 有没有错误的汉字、错位的元素或不可读的小字？
- 图示的连接关系是否准确？
- 是否有过量装饰、背景抢字、色彩失控？
- 是否留存了素材来源和输出版本？
