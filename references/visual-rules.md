# Mirage 视觉规范（当前审定版）

> 当前默认视觉方向：**暖白科技 3D 品牌风格（Warm White Tech 3D）**
> 状态：用户认可，可作为后续 Mirage 阿搭视觉创作的默认风格基线。
> 建立日期：2026-11-02
> 参考图：[ada-warm-white-tech-3d-v1.1.jpg](../assets/style-references/ada-warm-white-tech-3d-v1.1.jpg)

## 1. 品牌气质
- 关键词：温暖、聪明、亲切、轻科技、创造力、专业但不冰冷。
- 画面像成熟 AI 产品的品牌主视觉，不做复杂游戏海报，也不做廉价霓虹科技风。
- Mirage 的 M 标志与阿搭是主要品牌识别，不随意重绘或改变比例。

## 2. 阿搭角色锁定
阿搭是 Mirage 的河狸 AI 搭建员。优先保持：
- 圆润河狸脸、棕色蓬松毛发、奶油色口鼻与脸颊。
- 大而有神的棕色眼睛、两颗标志性门牙、宽鼻头。
- 紫色镜片护目镜、橙色耳侧夹扣。
- 白灰色科技工作服、深色内搭、橙色背带与工具配件。
- 胸前 M 徽章、明显的河狸扁尾。

允许按任务改变动作、表情、道具和场景；除非用户明确要求换装或重设计，不要改变脸型、毛色、护目镜、夹扣、门牙、尾巴等识别特征。风格参考图不替代角色母版图，也不代表角色三视图已经完成。

## 3. 色彩基线
以下为从用户认可的风格参考图提炼的近似色，不应宣称为已验证的官方品牌色值：

| 色彩角色 | 近似色值 | 用途 |
|---|---|---|
| Mirage 橙 | #FF861F | 强调、按钮、配件、重点图标 |
| Mirage 紫 | #A64BFF | 渐变、护目镜反光、科技强调 |
| 淡薰衣草紫 | #E7D1FF | 柔和背景形状、卡片光晕 |
| 暖白 | #FCF9FA | 主背景与留白 |
| 墨黑 | #20212A | 标题与正文 |
| 柔灰 | #C9C5D0 | 分隔线、次级信息 |

橙色与紫色作为点缀，不让大面积高饱和色压过阿搭主体。

## 4. 构图与版式
- 默认优先 4:3 横版；X 横幅按平台尺寸另行设计，并给头像遮挡区域留安全区。
- 阿搭是第一视觉主体，常规品牌宣传图中可占画面约 40%–55%。
- 标题与阿搭形成主次关系；标题优先使用高辨识度粗体，短句为主。
- 右侧或次要区域可放 2–3 个简洁功能图标卡片，避免堆叠大量 UI。
- 画面底部可用一条橙紫渐变弧线或柔和光带收束，不必每张都使用。
- 留白服务于阅读与层级，不用装饰填满空白。

## 5. 3D 材质与光线
- 高质量 3D 卡通写实：毛发蓬松但轮廓清楚，眼睛有自然高光，衣料与金属配件有真实材质差异。
- 柔和棚拍光、暖色轮廓光与轻微紫色环境反射。
- 阴影柔和，背景可有淡紫几何形状和轻微光晕。
- 避免过度锐利的赛博朋克光效、黑色重背景、厚重烟雾和密集粒子。

## 6. 图标与文字
- 图标采用简洁线性图形，橙色和紫色分工明确；置于暖白圆角卡片时可有轻微投影。
- 标题有个性但字形清楚、可读，不能为“灵性”牺牲辨识度。
- 中文标题、品牌名、产品名和小字说明优先在后期排版软件中准确添加。
- 生图阶段尽量只生成留白和无字版式；不要让图像模型承担大量中文文字、精确 Logo 或长段落。
- 一张图只保留一个主标题和少量辅助信息。

## 7. 不同用途的适配
- 品牌宣传图：突出阿搭、Mirage 标志与一句核心定位。
- X 主页横幅：横向延展背景，阿搭放在右侧或中右，左侧留出头像遮挡与主页信息安全区。
- 文章配图：用阿搭动作表达文章主题，文字只保留关键词。
- 一图拆解：信息结构优先，阿搭缩小为引导角色，确保图表和流程可读。
- 节日主题：可增加节日道具和服装细节，但保持角色身份与橙紫品牌识别。

## 8. 质量检查
- [ ] 是否一眼能认出是阿搭？
- [ ] 脸型、毛色、护目镜、橙色夹扣、门牙和扁尾是否保持一致？
- [ ] 橙紫是否克制、协调，没有变成霓虹堆叠？
- [ ] 背景是否干净，主次是否明确？
- [ ] 标题是否准确、易读，是否需要后期重新排字？
- [ ] 图标是否简洁且数量适中？
- [ ] 是否保留足够留白？
- [ ] 是否按投放平台检查比例与裁切安全区？

## 9. 审定边界
本规范记录用户对 2026-11-02 暖白科技 3D 视觉方向的认可。后续明确提出的特定主题、风格参考或配色要求优先于本规范。角色身份母版、三视图和完整服装资产仍需独立确认。
